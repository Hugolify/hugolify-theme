{{/* Analytics dispatcher: loads every configured analytics service. Called from layouts/_default/baseof.html, after the cookie banner and right before footer/scripts.html (which remains the user extension point), so that consent-gated scripts are in the DOM when CookieConsent starts. Rendered in production builds only. Google Analytics reads the native Hugo service (services.googleAnalytics.id). Every other service is configured in /config/_default/params.yaml, under `analytics`: a service is activated by the presence of its block. `true` is accepted too, and normalized to an empty map so that each partial can fail the build with an explicit `errorf` instead of an opaque template error. An empty block (`{}`) is ignored: an empty map is falsy in Go templates. Each partial handles its own consent: Google Analytics, Meta Pixel and Matomo with `cookies: true` wait for CookieConsent, the others are cookieless. Docs: https://www.hugolify.io/docs/getting-started/analytics/ */}} {{- if hugo.IsProduction }} {{- partial "footer/analytics/google-analytics.html" . }} {{- with site.Params.analytics }} {{- $config := . }} {{- range $service := slice "meta" "umami" "plausible" "matomo" "seline" "fathom" "goatcounter" "simpleanalytics" "cabin" }} {{- with index $config $service }} {{- partial (printf "footer/analytics/%s.html" $service) (cond (reflect.IsMap .) . dict) }} {{- end }} {{- end }} {{- end }} {{- end }}
