{{/* GetUntranslatedData A data file the site does not translate — data/organization.yml, data/schema.yml, data/blocks.yml — whichever shape the CMS saved it in. Sveltia CMS writes it flat. Decap CMS keys it by language all the same: it only reads the i18n of the collection, never the one of the file, so every file of the config collection, translated as a whole, comes out as `fr: {…}`, the values under the default language. A file keyed by the default language is read from there, a flat one as it is. Params: (string) the name of the data file, e.g. "schema". Returns: map, empty when the file is missing. */}} {{- $data := index hugo.Data . | default dict -}} {{- with index $data (partial "func/GetLanguage.html" (index hugo.Sites 0).Language).name -}} {{- if reflect.IsMap . -}}{{- $data = . -}}{{- end -}} {{- end -}} {{- return $data -}}
