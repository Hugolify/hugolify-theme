{{/* GetSchemaDate Format a date for schema.org, which reads ISO 8601. Takes what Hugo hands out — a time for .Date, .Lastmod and the like, a string for a date nested in front matter such as event.date_from — and returns RFC 3339. A bare day stays a bare day rather than gaining a midnight nobody set, and so does a bare month or year, all a founding date often comes down to — typed as a number too, the way YAML reads 1924. A value that does not parse is dropped rather than failing the build: structured data is no reason to stop a site. Params: (time, string or number) the date. Returns: string, empty when there is no date. */}} {{- $date := "" -}} {{- with . -}} {{- $raw := printf "%v" . -}} {{- if findRE `^\d{4}(-\d{2}){0,2}$` $raw -}} {{- $date = $raw -}} {{- else -}} {{- with try (time.AsTime .) -}} {{- if not .Err -}} {{- with .Value -}} {{- $date = .Format "2006-01-02T15:04:05Z07:00" -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- return $date -}}
