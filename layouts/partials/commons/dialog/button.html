{{/* Button — renders the trigger that opens a panel. Mirrors commons/dialog.html: the id drives both data-target and aria-controls, and the same expand param yields .panel-trigger-*, which css-components hides once the panel has gone inline. The pair therefore derives from one value and cannot disagree, wherever the button sits in the page — the filters one lives in the page heading, far from its panel. The native invoker comes from that param too — popovertarget for a popover, an invoker command for a — so the browser opens the panel by itself, without JavaScript. hugolify-theme-bootstrap, whose script opens the panels, overrides this partial without it. id (required) the panel's id content (required) the button's label, already rendered params the component's site params: .expand class extra classes, e.g. "btn btn-toc" or "btn-menu" ariaLabel accessible name when the label alone is not one attrs extra attributes, e.g. data-pagefind-ignore */}} {{- $expand := "md" }} {{- with .params }}{{ with .expand }}{{ $expand = . }}{{ end }}{{ end }} {{- $inline := ne $expand "none" }} {{- $classes := slice }} {{- with .class }}{{ $classes = $classes | append . }}{{ end }} {{- $classes = $classes | append "js-dialog-toggle" }} {{- if $inline }}{{ $classes = $classes | append (print "panel-trigger-" $expand) }}{{ end }}
