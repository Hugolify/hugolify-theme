{{/* A video Cloudinary hosts, see func/GetVideoSources.html, compressed on the fly at a size given as the images' ("WxH"), q_auto picking the compression: - a width or a height alone is the largest one served: c_limit, which never enlarges a smaller video - a width and a height, a crop that fills them around the centre: c_fill, which enlarges a smaller video (c_lfill, its limited form, is refused for a video). Not g_auto, the gravity of the images: Cloudinary draws it asynchronously for a video, a 423 until it is ready. Only the file as uploaded — nothing between /upload/ and its version, e.g. /video/upload/v1795009477/file.webm: a URL that carries transformations already is the editor's choice. Params: {map} url (string) the absolute URL of the video size (string) "Wx", "xH" or "WxH" Returns: string, the URL of the compressed copy — "" for a video Cloudinary does not host, or whose URL carries transformations. */}} {{- $src := "" -}} {{- if findRE `^https://res\.cloudinary\.com/[^/]+/video/upload/v\d+/` .url -}} {{- $crop := partial "func/isCrop.html" .size -}} {{- $params := slice (cond $crop "c_fill" "c_limit") | append (partial "func/GetCloudinarySize.html" .size) -}} {{- if $crop -}} {{- $params = $params | append "g_center" -}} {{- end -}} {{- $params = $params | append "q_auto" -}} {{- $src = replace .url "/upload/" (printf "/upload/%s/" (delimit $params ",")) 1 -}} {{- end -}} {{- return $src -}}
