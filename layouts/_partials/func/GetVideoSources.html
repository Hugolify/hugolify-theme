{{/* GetVideoSources The sources of a video, compressed by the CDN that hosts them: no wider than video.desktop (1920 px by default), and a copy no wider than video.mobile (720 px) for mobiles, which commons/video.html plays below 768 px (see video.js). One partial per CDN in commons/video/source/, named after it, as for the thumbnails (see func/GetVideoThumbnail.html): it recognises the URLs of the videos it hosts as uploaded and returns their compressed copy, "" for any other — a file it does not host, or one whose URL carries transformations already, the editor's choice. Adding a CDN is adding its partial and its name below; the first to answer wins. Uploadcare has none: it transcodes a video only through an asynchronous job of its REST API, its CDN answers a video operation with a 404. A mobile video the editor chose is kept, only compressed. The mobile copies are drawn from the desktop sources when the entry gives none: video.js plays the mobile sources first, so a webm copy of the desktop video beside a chosen mp4 would play instead of it. Params: the video (map: webm, mp4, webm_mobile, mp4_mobile…) Returns: map, the same video, its sources rewritten */}} {{- $video := . -}} {{- $desktopWidth := int (site.Params.video.desktop | default 1920) -}} {{- $mobileWidth := int (site.Params.video.mobile | default 720) -}} {{- $hasMobile := or $video.webm_mobile $video.mp4_mobile -}} {{/* Each source to compress, read before any rewrite */}} {{- $sources := slice -}} {{- range $format := slice "webm" "mp4" -}} {{- $mobile := printf "%s_mobile" $format -}} {{- $sources = $sources | append (dict "key" $mobile "url" (index $video (cond $hasMobile $mobile $format)) "width" $mobileWidth ) -}} {{- $sources = $sources | append (dict "key" $format "url" (index $video $format) "width" $desktopWidth ) -}} {{- end -}} {{- range $sources -}} {{- $source := . -}} {{- with .url -}} {{- range slice "cloudinary" -}} {{- with partial (printf "commons/video/source/%s.html" .) $source -}} {{- $video = merge $video (dict $source.key .) -}} {{- break -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- return $video -}}
