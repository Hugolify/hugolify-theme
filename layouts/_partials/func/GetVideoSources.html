{{/* GetVideoSources The sources of a video, compressed by the CDN that hosts them at two sizes, given as the images' ("WxH"): desktop, and mobile for the copy commons/video.html plays below 768 px (see video.js). A width alone ("720x") is the largest one served; a width and a height ("480x640") a crop around the centre, for a box whose shape the video does not have — a cover, portrait on mobiles. The caller gives them (hero.cover.video, blocks.pushes.video), else video.desktop and video.mobile: 1920 and 720 px wide by default. One partial per CDN in commons/video/source/, named after it, as for the thumbnails (see func/GetVideoThumbnail.html): it recognises the URLs of the videos it hosts as uploaded and returns their compressed copy, "" for any other — a file it does not host, or one whose URL carries transformations already, the editor's choice. Adding a CDN is adding its partial and its name below; the first to answer wins. Uploadcare has none: it transcodes a video only through an asynchronous job of its REST API, its CDN answers a video operation with a 404. A mobile video the editor chose is kept, only compressed. The mobile copies are drawn from the desktop sources when the entry gives none: video.js plays the mobile sources first, so a webm copy of the desktop video beside a chosen mp4 would play instead of it. Params: the video (map: webm, mp4, webm_mobile, mp4_mobile…), and desktop (string) optional, the size of the desktop sources mobile (string) optional, the size of the mobile ones Returns: map, the same video, its sources rewritten */}} {{- $video := . -}} {{/* The sizes, a bare width (1920) read as one ("1920x") */}} {{- $params := site.Params.video | default dict -}} {{- $sizes := dict -}} {{- range $device, $default := dict "desktop" "1920x" "mobile" "720x" -}} {{- $size := printf "%v" (index $video $device | default (index $params $device) | default $default) -}} {{- if not (strings.Contains $size "x") -}} {{- $size = printf "%sx" $size -}} {{- end -}} {{- $sizes = merge $sizes (dict $device $size) -}} {{- end -}} {{- $hasMobile := or $video.webm_mobile $video.mp4_mobile -}} {{/* Each source to compress, read before any rewrite */}} {{- $sources := slice -}} {{- range $format := slice "webm" "mp4" -}} {{- $mobile := printf "%s_mobile" $format -}} {{- $sources = $sources | append (dict "key" $mobile "url" (index $video (cond $hasMobile $mobile $format)) "size" $sizes.mobile ) -}} {{- $sources = $sources | append (dict "key" $format "url" (index $video $format) "size" $sizes.desktop ) -}} {{- end -}} {{- range $sources -}} {{- $source := . -}} {{- with .url -}} {{- range slice "cloudinary" -}} {{- with partial (printf "commons/video/source/%s.html" .) $source -}} {{- $video = merge $video (dict $source.key .) -}} {{- break -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- return $video -}}
