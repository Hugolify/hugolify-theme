{{/* GetUploadcareResize The Uploadcare operations for a fixed size: -/scale_crop/ when the size is a crop (WxH, with the alignment), else -/resize/, followed by the quality operation. Without an alignment, the segment is left out and Uploadcare crops around the center. Param: dict { size ("WxH", "Wx"…), crop (alignment, may be empty), quality (e.g. "-/quality/normal/") } Returns: string, e.g. "-/scale_crop/600x400/smart/-/quality/normal/" */}} {{- $params := printf "-/resize/%s/%s" .size .quality -}} {{- if partial "func/isCrop" .size -}} {{- $align := "" -}} {{- with .crop }}{{ $align = printf "%s/" . }}{{ end -}} {{- $params = printf "-/scale_crop/%s/%s%s" .size $align .quality -}} {{- end -}} {{- return $params -}}
